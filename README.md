# The Pet Fashion King — Character Sheets

An interactive flip-book of the character sheets for *The Pet Fashion King*.

- On computers, tablets and phones held sideways, it opens as a two-page book and the pages flip.
- On phones held upright, it shows one page at a time, and each page flips over to the next.
- Turn pages with the arrows, by tapping a page, by swiping, or with the ← → keys.

## Characters

Anthony · the boy in the red hoodie · Rob · Mom · Grandma · Bandit · Boogie · Kimba

## Files

- `index.html` — the flip-book page
- `img/` — the character sheets (a turnaround and a details sheet for each character)

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, set the source to **Deploy from a branch**.
3. Choose the `main` branch and the `/ (root)` folder, then click **Save**.
4. After a minute, the flip-book is live at `https://<your-username>.github.io/<repository-name>/`.
